LONGWICK-CUM-ILMER PARISH COUNCIL Meeting held 7-30 pm 2ND JUNE 60

[Margin: Present] C Harper C Claydon C Tappin C Claridge C Walker C Brock C Gomme

[Margin: Mins] Minutes of last meeting were read and confirmed

The Chairman opened the meeting by congratulating all present on their victory in the election especially the Three new Councillors

[Margin: Acceptance of office] The acceptance of office book was signed by all members.

[Margin: Election of officers] It was proposed by C Tappin seconded by C Walker that C Harper should continue as Chairman, a post he has so ably filled for a number years. Carried. It was proposed by C Walker seconded by C Gomme that C Claydon should continue as Vice Chairman Carried

[Margin: Bus Stop] It was agreed that the clerk should write to the TVTC High Wycombe supporting an application for a Request bus stop between the Red Lion and the Duke of Wellington

[Margin: General] It was agreed that the following matters should be incorporated in a letter to Mr Nobbs Divisional Surveyor. Mr Woods should be requested to trim back hedge in Bledlow Rd The need for a footpath in Station Rd should be stressed as a matter of priority. The Council would be interested to learn when it is proposed to bring main drainage to the parish

[Margin: Roads] It was proposed by C Walker seconded by C Claridge that the clerk should write to WRDC and protest at the use of the roads in this Parish, for what would appear to be experimental surfacing.

[Margin: Meadle Pond] C Brock raised the question of Meadle Pond and it would appear that Mrs Hamilton-Jenkins has taken possession, after discussion it was agreed that the matter should be referred to WRDC.

[Margin: Meetings] It was agreed generally that Monday would be the most suitable night for future meetings

[Margin: Parish Councils Assoc] It was proposed by C Claydon seconded by C Tappin that the clerk should write to the secretary of the Parish Councils Assoc and ask for a statement of the Assoc aims

[Margin: Station Rd] The renaming of Station Rd was discussed and various names were suggested, after discussion it was decided to leave the matter in abeyance Meeting Closed 8-30 pm W J Harper Aug 8 / 60
